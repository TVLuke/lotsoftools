General Information

This website provides a collection of privacy-friendly utility tools. We believe that simple online tools should not come at the cost of your privacy.

Data Processing

Most tools on this website process data entirely in your browser. Your data never leaves your device unless explicitly stated otherwise. For tools that require server-side processing, data is processed temporarily and immediately discarded — we do not store, log, or analyze your input.

Cookies

We only use essential cookies required for the website to function (e.g., language preference). We do not use tracking cookies, analytics, or any third-party advertising services.

Third-Party Services

Some tools may connect to external APIs to provide their functionality (e.g., holiday data, IBAN validation). These cases are clearly marked in the tool list below. When using such tools, please review the privacy policies of the respective external services.

Self-Hosting

This software is open source. If you have privacy concerns, you are welcome to run your own instance. See our GitHub repository for instructions.

Contact

If you have any questions about this privacy policy, please open an issue on our GitHub repository.
