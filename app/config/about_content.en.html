I got fed up with all these single-purpose websites full of tracking cookies, commercials, pop-ups, and shady buttons that serve you malware. You know the ones — they're always the first results in Google, not because they're good, but because they've SEO'd and paid their way to the top.

So I decided: whenever I was about to type something like "qr-code generator" or "uuid generator" into a search engine, I would instead just build my own.

This is that growing collection of tools. Privacy-friendly, no tracking, no ads.

How It Works

Most tools process data entirely in your browser — your data never leaves your device. For tools that require server processing, data is handled temporarily and immediately discarded.

Popular Categories

  • Developer Tools: JSON Formatter, XML Formatter, YAML Formatter, Base64 Encoder, Hash Generator
  • Generators: QR Code Generator, UUID Generator, Lorem Ipsum, Barcode Generator, Random String
  • Converters: Unit Converter, Color Converter, Coordinate Converter, Subtitle Converter
  • Map Tools: Distance Calculator, Radius Map, Map Marker, Location Simulator
  • Text Tools: Letter Counter, Diff Tool, Teleprompter
