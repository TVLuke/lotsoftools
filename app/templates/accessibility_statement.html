Erklärung zur Barrierefreiheit

Lots of Tools ist bestrebt, seine Website im Einklang mit den Web Content Accessibility Guidelines (WCAG) 2.1 barrierefrei zugänglich zu machen.

Diese Erklärung zur Barrierefreiheit gilt für https://lotsof.tools.

Stand der Konformität

Diese Website ist teilweise konform mit WCAG 2.1 Level AA.

  • Light Mode (Standard): Entspricht weitgehend WCAG 2.1 Level AA (Kontrastverhältnis 4,5:1).
  • Dark Mode: Entspricht weitgehend WCAG 2.1 Level AA (Kontrastverhältnis 4,5:1).
  • Hochkontrast-Modus: Entspricht WCAG 2.1 Level AAA (Kontrastverhältnis 7:1). Dieser Modus kann über das Theme-Menü in der Navigationsleiste aktiviert werden.

Wir führen regelmäßig automatisierte Tests durch, um die Barrierefreiheit zu überprüfen und zu verbessern.

Nicht barrierefreie Inhalte

Trotz unserer Bemühungen können einige Inhalte oder Funktionen möglicherweise nicht vollständig barrierefrei sein:

  • Einige interaktive Kartenkomponenten (Leaflet-basiert) haben möglicherweise eingeschränkte Tastaturnavigation.
  • Dynamisch generierte Inhalte in einigen Tools können temporäre Kontrastprobleme aufweisen.
  • Externe Bibliotheken und eingebettete Inhalte entsprechen möglicherweise nicht vollständig den Barrierefreiheitsstandards.

Die aktuellen automatisierten Testergebnisse finden Sie unter Barrierefreiheitsbericht (1.1.0).

Feedback und Kontaktmöglichkeiten

Wir nehmen Barrierefreiheit ernst. Wenn Sie auf Barrieren stoßen oder Verbesserungsvorschläge haben, kontaktieren Sie uns bitte:

  • E-Mail: lotsoftools@lukas-ruge.info
  • GitHub Issues: github.com/TVLuke/lotsoftools/issues

Wir bemühen uns, innerhalb von 2 Wochen auf Ihre Anfrage zu antworten.

Durchsetzungsverfahren

Hinweis: Als nicht-kommerzieller, privater Dienst unterliegt Lots of Tools nicht den gesetzlichen Verpflichtungen zur Barrierefreiheit nach dem Barrierefreiheitsstärkungsgesetz (BFSG) oder der BITV 2.0. Wir stellen diese Erklärung und die Barrierefreiheitsfunktionen freiwillig bereit, weil wir der Überzeugung sind, dass das Internet für alle zugänglich sein sollte.

Sollten Sie dennoch der Meinung sein, dass Ihre Anfrage nicht zufriedenstellend bearbeitet wurde, können Sie sich an die zuständige Schlichtungsstelle wenden. In Deutschland ist dies die Schlichtungsstelle nach dem Behindertengleichstellungsgesetz (BGG):

Accessibility Statement

Lots of Tools is committed to making its website accessible in accordance with the Web Content Accessibility Guidelines (WCAG) 2.1.

This accessibility statement applies to https://lotsof.tools.

Conformance Status

This website is partially conformant with WCAG 2.1 Level AA.

  • Light Mode (Default): Largely conforms to WCAG 2.1 Level AA (4.5:1 contrast ratio).
  • Dark Mode: Largely conforms to WCAG 2.1 Level AA (4.5:1 contrast ratio).
  • High Contrast Mode: Conforms to WCAG 2.1 Level AAA (7:1 contrast ratio). This mode can be activated via the theme menu in the navigation bar.

We regularly conduct automated tests to verify and improve accessibility.

Non-Accessible Content

Despite our efforts, some content or features may not be fully accessible:

  • Some interactive map components (Leaflet-based) may have limited keyboard navigation.
  • Dynamically generated content in some tools may have temporary contrast issues.
  • External libraries and embedded content may not fully comply with accessibility standards.

Current automated test results can be found at Accessibility Report (1.1.0).

Feedback and Contact

We take accessibility seriously. If you encounter barriers or have suggestions for improvement, please contact us:

  • Email: lotsoftools@lukas-ruge.info
  • GitHub Issues: github.com/TVLuke/lotsoftools/issues

We aim to respond to your inquiry within 2 weeks.

Enforcement Procedure

Note: As a non-commercial, private service, Lots of Tools is not subject to legal accessibility requirements under the European Accessibility Act (EAA) or similar regulations. We provide this statement and accessibility features voluntarily because we believe the internet should be accessible to everyone.

If you still believe your request has not been satisfactorily addressed, you may contact the relevant arbitration body. In Germany, this is the Schlichtungsstelle nach dem Behindertengleichstellungsgesetz (BGG):

Technical Information

This website was built with the following technologies:

  • HTML5, CSS3, JavaScript
  • Bootstrap 5 Framework
  • CSS variables for consistent theming and theme support

Note: ARIA support is being continuously improved. Form fields use proper label associations, but some interactive elements may need additional ARIA attributes.

Preparation of this Statement

This statement was prepared on January 24, 2026 and is reviewed regularly.

The assessment is conducted through automated testing with axe-core and manual reviews.
